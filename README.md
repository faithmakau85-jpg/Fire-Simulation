# Forest Fire Spread Simulation Using Cellular Automata

## Project overview
This project models the spread of a forest fire using a Cellular Automata (CA) model in MATLAB. The forest is represented by a 50 by 50 grid. Each cell represents one tree and can be healthy, burning, or burnt.

## Tree states
- `1` – Healthy (green)
- `2` – Burning (red)
- `3` – Burnt (dark grey)

## Model rules
1. The simulation starts with all trees healthy except one burning tree at the centre of the grid.
2. The Moore neighbourhood consists of the eight surrounding cells, including diagonal neighbours.
3. A healthy tree with at least one burning neighbour has a 60% chance of catching fire.
4. A burning tree becomes burnt in the next time step.
5. A burnt tree remains burnt.
6. The simulation stops when no burning trees remain or the maximum number of steps is reached.

## Limitations
This is a simplified model. It assumes a uniform forest, does not include wind, slope, humidity, or changing weather, and uses a fixed fire-spread probability. It is intended for learning and for exploring how local neighbourhood rules can produce larger fire patterns; it is not a real-world fire prediction tool.
